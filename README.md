## 📌 Project Overview

This project builds a binary classification machine learning pipeline to **predict diabetes risk** based on clinical parameters derived from the Pima Indians Diabetes dataset (extended healthcare version). The pipeline covers end-to-end data preprocessing, exploratory data analysis, model training, evaluation, and an interactive web application for real-time predictions.

---

## 🤖 Machine Learning Model Description

Two classification models are trained and evaluated:

| Model | Description |
|-------|-------------|
| **Random Forest** | Ensemble of decision trees using bagging. Handles non-linear relationships, provides feature importance, robust to outliers. Key hyperparameters: `n_estimators=200`, `max_depth=8`, `class_weight='balanced'`. |
| **Logistic Regression** | Linear baseline classifier. Fast, interpretable, works well on scaled data. `max_iter=1000`, `class_weight='balanced'`. |

**Preprocessing steps:**
- Biologically invalid zero values replaced with `NaN` for `Glucose`, `BloodPressure`, `SkinThickness`, `Insulin`, `BMI`
- Median imputation applied to missing values
- `StandardScaler` applied to all features
- Stratified 80/20 train-test split

**Evaluation metrics:** Accuracy, Precision, Recall, F1-Score, ROC-AUC, Confusion Matrix

## ⚙️ Setup & Run Instructions

### 1. Clone / Download the Project
```bash
# Navigate to your project folder
cd Healthcare_Diabetes_Project
```

### 2. Create a Virtual Environment (Recommended)
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Jupyter Notebook (ML Pipeline)
```bash
jupyter notebook Jahid_Shahid_Patel_HealthcareDiabetes.ipynb
```
Run all cells from top to bottom. This will:
- Perform EDA and save all plots as `.png` files
- Train both models
- Save model artifacts (`rf_model.pkl`, `lr_model.pkl`, `scaler.pkl`, `imputer.pkl`)
- Write `app.py` (the Streamlit Web UI)

### 5. Launch the Streamlit Web UI
After running the notebook, start the interactive app:
```bash
streamlit run app.py
```
The app will open automatically at `http://localhost:8501` in your browser.

## 📊 Dataset Information

- **Source:** [Kaggle — Healthcare Diabetes](https://www.kaggle.com/datasets/nanditapore/healthcare-diabetes)
- **Rows:** 2,768 patient records
- **Features (9):** `Pregnancies`, `Glucose`, `BloodPressure`, `SkinThickness`, `Insulin`, `BMI`, `DiabetesPedigreeFunction`, `Age`
- **Target:** `Outcome` — `1` = Diabetic, `0` = Non-Diabetic
